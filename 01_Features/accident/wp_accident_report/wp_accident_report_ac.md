# Acceptance Criteria — Web Portal, Accident Reports (`WPAR`)

## User Story

**As a** Web Portal Admin
**I want** to view, filter, sort, inspect the damage/photo/document details of, and delete accident reports submitted by all users
**So that** I can monitor and manage the accident reports that users have submitted through the app's `MA` (`wa_my_accident`) and `AA` (`wa_accident_assistant`) flows, without leaving the portal
