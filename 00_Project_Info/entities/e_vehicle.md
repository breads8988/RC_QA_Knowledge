# Vehicle

A car owned by a User. Registered during sign-up (step "Register Vehicle") and managed afterwards on the My Vehicles page. MCS Admin can view vehicles across all tenants.

API module: `Vehicles` (CRUD, list per user).

Source: [[00_Project_Info/system-high-level-design]] §3A, §3D, §4, §6.
