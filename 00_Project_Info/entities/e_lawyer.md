# Lawyer (*Unfall Rechtsberatung*)

A lawyer offering accident legal advice. **Master data, geo-located** — filtered by **rating**. Drivers list lawyers and request an appointment. Client Admins add / edit / delete and import / export lawyers in the Web Portal; MCS Admin maintains the global list.

API modules: `Lawyers` (filter by rating), `Geocoding`.
